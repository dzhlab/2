## 1. Введение

### 1.1. Общие положения

Правила FIG 2025-2028 регламентируют судейство соревнований по художественной гимнастике на международном уровне. Данный документ адаптирует официальные правила для разработки программного обеспечения.

### 1.2. Типы соревнований

| Тип | Формат | Количество упражнений |
|-----|--------|-----------------------|
| **Индивидуальное многоборье** | Все 4-5 предметов | 4 (обруч, мяч, булавы, лента) |
| **Финалы по предметам** | Отдельно каждый предмет | 1 |
| **Групповое многоборье** | 2 упражнения | 1 с 5 одинаковыми + 1 с разными |

### 1.3. Возрастные категории

| Категория | Возраст | Особенности судейства |
|-----------|---------|----------------------|
| **Младшие** | 6-10 лет | Упрощённые требования D |
| **Девочки** | 11-12 лет | Базовые требования |
| **Юниорки** | 13-15 лет | Полные требования FIG |
| **Сениорки** | 16+ лет | Полные требования FIG |

### 1.4. Предметы

**Индивидуальные:**
- Скакалка (Rope) — *исключена из олимпийской программы с 2024*
- Обруч (Hoop)
- Мяч (Ball)
- Булавы (Clubs) — 2 шт.
- Лента (Ribbon)

**Групповые:**
- 5 одинаковых предметов
- Комбинация (например: 3 мяча + 2 ленты)

## 2. Структура судейства

### 2.1. Состав судейских бригад

#### D-бригада (Difficulty Panel)

| Параметр | Значение |
|----------|----------|
| **Функция** | Оценка сложности упражнения |
| **Количество судей** | **2** (D1, D2) |
| **Независимость** | Судят независимо друг от друга |
| **Диапазон оценок** | 0.0 - 20.0+ (теоретически безграничен) |
| **Метод расчёта** | Среднее арифметическое: `D = (D1 + D2) / 2` |

**Подкомпоненты оценки D:**
```
D = D_body + D_apparatus + D_dance

D_body      = Сумма 9 лучших элементов тела (BD > 0)
D_apparatus = Элементы с предметом (AD) + риски (R)
D_dance     = Обязательные танцевальные шаги
```

#### E-бригада (Execution Panel)

| Параметр | Значение |
|----------|----------|
| **Функция** | Оценка качества исполнения |
| **Количество судей** | **4-6** (обычно 4: E1-E4) |
| **Независимость** | Судят независимо |
| **Система** | Сбавки от **10.0** |
| **Метод расчёта** | Среднее без макс/мин (см. раздел 4.4) |

**Критерии сбавок:**
- Техника тела (ноги, руки, осанка)
- Работа с предметом (потери, неточности)
- Музыкальность и синхронность

#### A-бригада (Artistic Panel)

| Параметр | Значение |
|----------|----------|
| **Функция** | Оценка артистизма |
| **Количество судей** | **2-4** (обычно 2: A1, A2) |
| **Независимость** | Судят независимо |
| **Диапазон оценок** | 0.0 - 10.0 |
| **Метод расчёта** | Среднее арифметическое: `A = (A1 + A2) / 2` |

**Критерии:**
- Музыкальность и выразительность
- Хореография и композиция
- Оригинальность и креативность
- Единство музыки и движения

### 2.2. Временные рамки

| Действие | Время |
|----------|-------|
| **Разминка на ковре** | 30 сек (индивид.) / 60 сек (группа) |
| **Выступление индивид.** | 1'15" - 1'30" (75-90 сек) |
| **Выступление группа** | 2'15" - 2'30" (135-150 сек) |
| **Выставление оценки** | До 2 минут |
| **Консенсус (при расхождении)** | +1-2 минуты |

**Сбавки за время:**
```javascript
if (time < min_time || time > max_time) {
    penalty = 0.05 за каждую неполную секунду
}
```

## 3. Оценка D (Difficulty) — Сложность

### 3.1. Компоненты оценки D

#### 3.1.1. D_body — Сложность элементов тела

**Правило:** Учитываются **9 лучших** элементов с ценностью BD > 0

**Уровни сложности элементов:**

| Уровень | Буквенное обозначение | Стоимость (BD) | Примеры |
|---------|----------------------|----------------|---------|
| 1 | A | 0.10 | Прыжок шагом, волна |
| 2 | B | 0.20 | Шпагат прыжком |
| 3 | C | 0.30 | Перекидной, колесо |
| 4 | D | 0.40 | Фуэте 360°, шпагат кольцом |
| 5 | E | 0.50 | Фуэте 540°, кольцо назад |
| 6 | F | 0.60 | Сложные вращения, прыжки |
| 7 | G | 0.70 | Элементы высшей сложности |
| 8+ | H, I, ... | 0.80+ | Уникальные элементы |

**Формула:**
```
D_body = Σ (9 лучших BD элементов)

Максимум теоретический = 9 × 0.70+ = 6.3+ балла
```

**Категории элементов тела:**
1. **Прыжки (Jumps/Leaps)** — J
2. **Равновесия (Balances)** — B
3. **Вращения (Rotations/Pivots)** — R
4. **Гибкость (Flexibility)** — F

**Требование:** Минимум **1 элемент из каждой категории** (J, B, R, F)

```javascript
// Валидация
if (!hasJump || !hasBalance || !hasRotation || !hasFlexibility) {
    WARNING: "Отсутствует элемент из обязательной категории"
    // Судьи могут применить нейтральную сбавку
}
```

#### 3.1.2. D_apparatus — Работа с предметом

**Компоненты:**
```
D_apparatus = AD + R

AD = Apparatus Difficulty (сложность работы с предметом)
R  = Risks (риски)
```

**AD — Элементы с предметом:**

| Тип | Описание | Стоимость | Максимум учитываемых |
|-----|----------|-----------|----------------------|
| **AD** | Технические элементы с предметом | 0.10 - 0.60+ | **Все выполненные** |
| **Мастерство** | Виртуозная работа | 0.10 - 0.20 | — |

Примеры AD:
- Броски и ловли (высота > 2м роста)
- Перекаты по телу
- Вращения предмета
- Спирали, восьмёрки (лента)
- Отбивы, вращения (мяч)

**R — Риски:**

| Уровень риска | Обозначение | Стоимость | Примеры |
|---------------|-------------|-----------|---------|
| Низкий | R1 | 0.10 | Бросок с поворотом 360° |
| Средний | R2 | 0.20 | Бросок с двойным поворотом |
| Высокий | R3 | 0.30 | Бросок через перекат, ловля в шпагат |
| Экстремальный | R4 | 0.40+ | Комбинации рисков |

**Максимальное количество рисков:** Не ограничено, но обычно 5-7 за упражнение

```javascript
// Расчёт D_apparatus
let D_apparatus = 0;

// AD элементы - все выполненные
for (let ad of apparatus_elements) {
    D_apparatus += ad.value; // 0.10 - 0.60
}

// Риски
for (let risk of risks) {
    D_apparatus += risk.value; // 0.10 - 0.40
}
```

#### 3.1.3. D_dance — Танцевальные шаги

**Обязательное требование:** Минимум **1 танцевальная дорожка**

**Критерии:**
- Длительность: минимум 8 секунд
- Должна включать разнообразные шаги
- Должна покрывать площадку

**Стоимость:**
```
D_dance = 0.0 (нет дорожки) или включено в базу
```

**Сбавка за отсутствие:**
```javascript
if (!hasDanceSteps) {
    PENALTY: -0.30 (нейтральная сбавка)
}
```

### 3.2. Пример расчёта D

**Упражнение с обручем:**

```
D_body:
  1. Шпагат прыжком (B) = 0.20
  2. Фуэте 360° (D) = 0.40
  3. Кольцо назад (E) = 0.50
  4. Перекидной (C) = 0.30
  5. Равновесие Аттитюд (D) = 0.40
  6. Прыжок кольцо (E) = 0.50
  7. Вращение 720° (F) = 0.60
  8. Волна (A) = 0.10
  9. Шпагат кольцом (D) = 0.40
  → D_body = 3.40

D_apparatus (AD + R):
  AD элементы:
    - Бросок с перекатом = 0.30
    - Вращение обруча на руке = 0.20
    - Проход через обруч = 0.20
    - Вращение обруча + кувырок = 0.40
  Риски:
    - Бросок с поворотом 720° (R2) = 0.20
    - Ловля в шпагат (R3) = 0.30
  → D_apparatus = 1.60

D_dance:
  - Танцевальная дорожка 8 сек ✅

ИТОГО: D = 3.40 + 1.60 = 5.00
```

### 3.3. Консенсус D-бригады

**Правило:** Если разница между D1 и D2 **> 0.50**, требуется консенсус

```javascript
D1 = 5.20
D2 = 4.60
difference = Math.abs(D1 - D2) = 0.60

if (difference > 0.50) {
    // Судьи D1 и D2 обсуждают и корректируют
    // Каждый может изменить оценку 1 раз

    D1_final = 5.00  // скорректировал
    D2_final = 4.80  // скорректировал

    D = (D1_final + D2_final) / 2 = 4.90
}
```

**Для ПО:**
```javascript
function calculateD(D1, D2) {
    const difference = Math.abs(D1 - D2);

    if (difference > 0.5) {
        return {
            status: "CONSENSUS_REQUIRED",
            D1: D1,
            D2: D2,
            difference: difference,
            message: "Разница > 0.5, требуется консенсус"
        };
    }

    return {
        status: "OK",
        D: (D1 + D2) / 2,
        D1: D1,
        D2: D2
    };
}
```

## 4. Оценка E (Execution) — Исполнение

### 4.1. Принцип оценки

**Базовая оценка:** 10.0 (идеальное исполнение)

**Система:** Сбавки за ошибки вычитаются из 10.0

```
E = 10.0 - Σ(сбавки)
```

### 4.2. Категории сбавок

#### 4.2.1. Техника тела

| Ошибка | Сбавка | Примеры |
|--------|--------|---------|
| **Мелкая** | -0.10, -0.20, -0.30 | Неточность позиции рук, недостаточное натяжение носков |
| **Средняя** | -0.50 | Согнутые ноги в прыжке, потеря равновесия (1 шаг) |
| **Крупная** | -0.80, -1.00 | Падение на колено, касание предмета телом |
| **Критическая** | -1.50+ | Падение, полная потеря контроля |

**Детализация:**

```javascript
const E_penalties = {
    // Ноги
    legs: {
        slight_bend: -0.10,        // Небольшое сгибание
        bent_knees: -0.30,         // Согнутые колени
        crossed_legs: -0.50,       // Скрещенные ноги в прыжке
    },

    // Стопы
    feet: {
        flexed_feet: -0.10,        // Не оттянуты носки
        incorrect_landing: -0.30,  // Неправильное приземление
    },

    // Равновесие
    balance: {
        small_adjustment: -0.10,    // Небольшая коррекция
        one_step: -0.50,            // 1 шаг для удержания
        multiple_steps: -0.80,      // Несколько шагов
        touch_floor_hand: -1.00,    // Касание пола рукой
        fall: -1.50,                // Падение
    },

    // Осанка
    posture: {
        hunched_shoulders: -0.10,   // Сгорбленные плечи
        incorrect_head: -0.10,      // Неправильное положение головы
    }
};
```

#### 4.2.2. Работа с предметом

| Ошибка | Сбавка | Примеры |
|--------|--------|---------|
| **Мелкая неточность** | -0.10 | Касание предмета телом (допустимое) |
| **Потеря контроля** | -0.30 | Предмет отклонился от траектории |
| **Потеря предмета** | -0.50 | Предмет упал, но быстро поднят |
| **Выход за площадку** | -0.50 | Предмет за пределами ковра |
| **Критическая ошибка** | -1.00+ | Длительная потеря, неудачная ловля |

**Специфические ошибки по предметам:**

```javascript
const apparatus_penalties = {
    // Обруч
    hoop: {
        deformed_shape: -0.10,        // Деформация формы
        incorrect_rotation: -0.30,     // Неправильное вращение
        dropped: -0.50,                // Падение
    },

    // Мяч
    ball: {
        uncontrolled_bounce: -0.30,   // Неконтролируемый отскок
        rolled_away: -0.50,            // Мяч укатился
        caught_with_arms: -0.10,      // Ловля руками (не кистями)
    },

    // Булавы
    clubs: {
        clubs_touch: -0.10,            // Булавы столкнулись
        one_dropped: -0.50,            // Одна булава упала
        both_dropped: -1.00,           // Обе булавы упали
    },

    // Лента
    ribbon: {
        knot: -0.50,                   // Узел на ленте
        wrapped_around: -0.30,         // Обмоталась вокруг палочки
        touched_floor: -0.10,          // Касание ленты об пол
    }
};
```

#### 4.2.3. Музыкальность

| Ошибка | Сбавка |
|--------|--------|
| **Небольшое несовпадение** | -0.10 |
| **Явное несовпадение с музыкой** | -0.30 |
| **Завершение до/после музыки** | -0.50 |

### 4.3. Расчёт консенсуса E-бригады

**Метод:** Убрать максимальную и минимальную оценки, вычислить среднее из оставшихся

**Стандартная бригада: 4 судьи (E1, E2, E3, E4)**

```javascript
function calculateE(scores) {
    // scores = [E1, E2, E3, E4]
    // Сортируем
    const sorted = [...scores].sort((a, b) => a - b);

    // Убираем min и max
    const min = sorted[0];
    const max = sorted[sorted.length - 1];
    const middle = sorted.slice(1, -1);

    // Среднее из средних
    const E = middle.reduce((a, b) => a + b, 0) / middle.length;

    return {
        E: E.toFixed(3),
        scores: scores,
        dropped: {min: min, max: max},
        used: middle
    };
}

// Пример
const scores = [9.200, 8.900, 8.850, 8.500];
const result = calculateE(scores);

/*
Result:
{
    E: "8.875",
    scores: [9.200, 8.900, 8.850, 8.500],
    dropped: { min: 8.500, max: 9.200 },
    used: [8.900, 8.850]
}

E = (8.900 + 8.850) / 2 = 8.875
*/
```

**Если 6 судей (E1-E6):**

```javascript
// Убираем 1 min и 1 max, берём среднее из 4 средних
const scores = [9.1, 9.0, 8.9, 8.8, 8.7, 8.5];
const sorted = [8.5, 8.7, 8.8, 8.9, 9.0, 9.1];
const middle = [8.7, 8.8, 8.9, 9.0];
const E = (8.7 + 8.8 + 8.9 + 9.0) / 4 = 8.85
```

### 4.4. Проверка расхождений

**Правило:** Если разброс между судьями **> 1.0**, требуется пересмотр

```javascript
function checkEDiscrepancy(scores) {
    const min = Math.min(...scores);
    const max = Math.max(...scores);
    const range = max - min;

    if (range > 1.0) {
        return {
            status: "WARNING",
            range: range,
            message: "Большой разброс оценок E-судей",
            action: "Рекомендуется пересмотр"
        };
    }

    return { status: "OK" };
}

// Пример
checkEDiscrepancy([9.2, 8.9, 8.0, 8.5]);
// range = 9.2 - 8.0 = 1.2 → WARNING
```

```
Упражнение: Индивидуальное с лентой

Сбавки судьи E1:
  - Согнутые ноги в прыжке: -0.30
  - Лента коснулась пола: -0.10
  - 1 шаг для равновесия: -0.50
  - Небольшая неточность рук: -0.10
  → E1 = 10.0 - 1.00 = 9.00

Сбавки судьи E2:
  - Согнутые ноги: -0.30
  - Касание пола: -0.10
  - Шаг для равновесия: -0.50
  - Узел на ленте: -0.50
  → E2 = 10.0 - 1.40 = 8.60

Сбавки судьи E3:
  - Согнутые ноги: -0.30
  - Шаг для равновесия: -0.50
  - Неточность рук: -0.10
  - Касание пола: -0.10
  - Несовпадение с музыкой: -0.10
  → E3 = 10.0 - 1.10 = 8.90

Сбавки судьи E4:
  - Согнутые ноги: -0.30
  - Шаг: -0.50
  - Узел на ленте: -0.50
  - Касание пола: -0.10
  → E4 = 10.0 - 1.40 = 8.60

Оценки: [9.00, 8.60, 8.90, 8.60]
Убираем: max = 9.00, min = 8.60
Средние: [8.60, 8.90]

E = (8.60 + 8.90) / 2 = 8.75
```

## 5. Оценка A (Artistic) — Артистизм

### 5.1. Критерии оценки

**Диапазон:** 0.0 - 10.0

**4 основных критерия:**

#### 5.1.1. Музыкальность (Musical Sensitivity)

| Аспект | Оценка |
|--------|--------|
| **Интерпретация музыки** | Движения отражают характер музыки |
| **Синхронность** | Совпадение движений с акцентами |
| **Выразительность** | Эмоциональная передача музыки |

**Сбавки:**
- Несоответствие характеру музыки: -0.10 до -0.50
- Монотонность: -0.30

#### 5.1.2. Хореография (Choreography)

| Аспект | Оценка |
|--------|--------|
| **Разнообразие элементов** | Баланс прыжков, вращений, гибкости |
| **Использование пространства** | Весь ковёр 13×13м |
| **Уровни** | Работа на разной высоте (пол, стоя, прыжки) |
| **Направления** | Движения во всех направлениях |

**Сбавки:**
- Монотонность композиции: -0.30
- Недостаточное использование площадки: -0.20

#### 5.1.3. Единство (Unity)

| Аспект | Оценка |
|--------|--------|
| **Музыка + движение** | Гармоничное слияние |
| **Предмет + тело** | Предмет - продолжение тела |
| **Стиль** | Единый стиль упражнения |

#### 5.1.4. Оригинальность (Originality)

| Аспект | Оценка |
|--------|--------|
| **Уникальные элементы** | Нестандартные связки |
| **Креативность** | Авторский подход |

### 5.2. Расчёт A

**Метод:** Среднее арифметическое оценок судей

```javascript
function calculateA(A1, A2) {
    const A = (A1 + A2) / 2;

    return {
        A: A.toFixed(3),
        A1: A1,
        A2: A2
    };
}

// Пример
A1 = 9.100
A2 = 9.200
A = (9.100 + 9.200) / 2 = 9.150
```

**Если 4 судьи (A1-A4):**

## 6. Расчёт итоговой оценки

### 6.1. Формула

**Базовая формула:**
```
TOTAL = D + E + A
```

Где:
- **D** — сложность (0.0+)
- **E** — исполнение (0.0 - 10.0)
- **A** — артистизм (0.0 - 10.0)

**Теоретический максимум:** ~25-30 баллов (зависит от сложности D)

### 6.2. Альтернативная формула (некоторые соревнования)

```
TOTAL = D + (10 - E_deductions) + A
```

Где:
- E_deductions = сумма сбавок E-бригады

**Эквивалентно базовой формуле**, но показывает логику расчёта

### 6.3. Пример полного расчёта

**Выступление: Индивидуальное с обручем**

```
D-бригада:
  D1 = 5.20
  D2 = 5.10
  → D = (5.20 + 5.10) / 2 = 5.15

E-бригада:
  E1 = 9.00
  E2 = 8.60
  E3 = 8.85
  E4 = 8.70

  Sorted: [8.60, 8.70, 8.85, 9.00]
  Drop: min=8.60, max=9.00
  Middle: [8.70, 8.85]

  → E = (8.70 + 8.85) / 2 = 8.775

A-бригада:
  A1 = 9.10
  A2 = 9.20
  → A = (9.10 + 9.20) / 2 = 9.15

ИТОГО:
  TOTAL = 5.15 + 8.775 + 9.15 = 23.075
```

### 6.4. Реализация для ПО

```javascript
class PerformanceScore {
    constructor() {
        this.D1 = 0;
        this.D2 = 0;
        this.E_scores = []; // массив из 4-6 оценок
        this.A1 = 0;
        this.A2 = 0;
    }

    calculateD() {
        const diff = Math.abs(this.D1 - this.D2);

        if (diff > 0.5) {
            return {
                status: "CONSENSUS_REQUIRED",
                value: null
            };
        }

        return {
            status: "OK",
            value: (this.D1 + this.D2) / 2
        };
    }

    calculateE() {
        if (this.E_scores.length < 4) {
            return { status: "ERROR", value: null };
        }

        const sorted = [...this.E_scores].sort((a, b) => a - b);
        const middle = sorted.slice(1, -1);
        const E = middle.reduce((a, b) => a + b, 0) / middle.length;

        return {
            status: "OK",
            value: parseFloat(E.toFixed(3))
        };
    }

    calculateA() {
        const A = (this.A1 + this.A2) / 2;

        return {
            status: "OK",
            value: parseFloat(A.toFixed(3))
        };
    }

    calculateTotal() {
        const D = this.calculateD();
        const E = this.calculateE();
        const A = this.calculateA();

        if (D.status !== "OK" || E.status !== "OK" || A.status !== "OK") {
            return {
                status: "ERROR",
                message: "Не все оценки готовы",
                D: D,
                E: E,
                A: A
            };
        }

        const total = D.value + E.value + A.value;

        return {
            status: "OK",
            D: D.value,
            E: E.value,
            A: A.value,
            Total: parseFloat(total.toFixed(3))
        };
    }
}

// Использование
const score = new PerformanceScore();
score.D1 = 5.20;
score.D2 = 5.10;
score.E_scores = [9.00, 8.60, 8.85, 8.70];
score.A1 = 9.10;
score.A2 = 9.20;

const result = score.calculateTotal();
console.log(result);
/*
{
    status: "OK",
    D: 5.15,
    E: 8.775,
    A: 9.15,
    Total: 23.075
}
*/
```

## 7. Правила ранжирования

### 7.1. Базовое ранжирование

**Правило:** Сортировка по **Total** в порядке убывания

```javascript
athletes.sort((a, b) => b.Total - a.Total);
```

### 7.2. Тай-брейк (при равенстве Total)

**Последовательность правил:**

```
1. Выше E (исполнение)
2. Выше D (сложность)
3. Выше A (артистизм)
4. Равные места (если всё равно)
```

**Алгоритм:**

```javascript
function compareAthletes(a, b) {
    // 1. Сравнение по Total
    if (a.Total !== b.Total) {
        return b.Total - a.Total; // По убыванию
    }

    // 2. Тай-брейк: выше E
    if (a.E !== b.E) {
        return b.E - a.E;
    }

    // 3. Тай-брейк: выше D
    if (a.D !== b.D) {
        return b.D - a.D;
    }

    // 4. Тай-брейк: выше A
    if (a.A !== b.A) {
        return b.A - a.A;
    }

    // 5. Равные места
    return 0;
}

athletes.sort(compareAthletes);
```

### 7.4. Реализация для многоборья

**Многоборье:** Сумма оценок всех предметов

```javascript
function calculateAllAround(athlete) {

    const total = athlete.hoop + athlete.ball +
                  athlete.clubs + athlete.ribbon;

    return {

        ribbon: athlete.ribbon,
        total: total
    };

// Сортировка

```

**Тай-брейк в многоборье:**
```
1. Выше сумма всех Total
2. Выше сумма всех E
3. Выше сумма всех D
4. Выше лучший результат в одном предмете
5. Равные места
```

```javascript
function compareAllAround(a, b) {
    // 1. Сумма Total
    if (a.total !== b.total) {
        return b.total - a.total;
    }

    // 2. Сумма E
    const sumE_a = a.hoop_E + a.ball_E + a.clubs_E + a.ribbon_E;
    const sumE_b = b.hoop_E + b.ball_E + b.clubs_E + b.ribbon_E;
    if (sumE_a !== sumE_b) {
        return sumE_b - sumE_a;
    }

    // 3. Сумма D
    const sumD_a = a.hoop_D + a.ball_D + a.clubs_D + a.ribbon_D;
    const sumD_b = b.hoop_D + b.ball_D + b.clubs_D + b.ribbon_D;
    if (sumD_a !== sumD_b) {
        return sumD_b - sumD_a;
    }

    // 4. Лучший результат
    const maxA = Math.max(a.hoop, a.ball, a.clubs, a.ribbon);
    const maxB = Math.max(b.hoop, b.ball, b.clubs, b.ribbon);
    if (maxA !== maxB) {
        return maxB - maxA;
    }

    return 0; // Равные
}
```

## 8. Технические требования к упражнениям

### 8.1. Длительность

| Тип | Минимум | Максимум | Сбавка за нарушение |
|-----|---------|----------|---------------------|
| **Индивидуальное** | 1'15" (75 сек) | 1'30" (90 сек) | -0.05 за каждую неполную секунду |
| **Групповое** | 2'15" (135 сек) | 2'30" (150 сек) | -0.05 за каждую неполную секунду |

```javascript
function checkDuration(type, duration) {
    const limits = {
        individual: { min: 75, max: 90 },
        group: { min: 135, max: 150 }
    };

    const { min, max } = limits[type];

    if (duration < min) {
        const penalty = (min - duration) * 0.05;
        return {
            status: "PENALTY",
            penalty: penalty,
            message: `Упражнение короче на ${min - duration} сек`
        };
    }

    if (duration > max) {
        const penalty = (duration - max) * 0.05;
        return {
            status: "PENALTY",
            penalty: penalty,
            message: `Упражнение длиннее на ${duration - max} сек`
        };
    }

    return { status: "OK" };
}

|------------|----------|----------------------|
| **Категории элементов** | Минимум 1 из каждой: J, B, R, F | -0.30 (нейтральная) |
| **Танцевальная дорожка** | Минимум 8 секунд | -0.30 (нейтральная) |

**Категории элементов тела:**

function validateRequiredElements(routine) {
    const penalties = [];

    // Проверка категорий
    const categories = ['J', 'B', 'R', 'F'];
    for (const cat of categories) {
        if (!routine.elements.some(el => el.category === cat)) {
            penalties.push({
                type: 'MISSING_CATEGORY',
                category: cat,
                penalty: 0.30,
                message: `Отсутствует элемент категории ${cat}`
            });
        }
    }

    // Проверка танцевальной дорожки
    if (!routine.hasDanceSteps || routine.danceStepsDuration < 8) {
        penalties.push({
            type: 'MISSING_DANCE',
            penalty: 0.30,
            message: 'Отсутствует танцевальная дорожка (мин. 8 сек)'
        });
    }

    return penalties;
}
```

## 11. Валидация и проверки

### 11.1. Диапазоны оценок

```javascript
const SCORE_RANGES = {
    D: { min: 0.0, max: 20.0 },      // Теоретически безграничен, но 20+ редко
    E: { min: 0.0, max: 10.0 },      // От 10.0 вычитаются сбавки
    A: { min: 0.0, max: 10.0 }
};

function validateScore(panel, score) {
    const range = SCORE_RANGES[panel];

    if (score < range.min || score > range.max) {
        return {
            valid: false,
            error: `Оценка ${panel} вне диапазона [${range.min}, ${range.max}]`,
            score: score
        };
    }

    return { valid: true };
}
```

### 11.2. Проверка консенсуса

```javascript
const CONSENSUS_THRESHOLDS = {
    D: 0.50,   // Разница > 0.5 → консенсус обязателен
    E: 1.00,   // Разброс > 1.0 → предупреждение
    A: 0.50    // Разница > 0.5 → консенсус рекомендован
};

function checkConsensus(panel, scores) {
    const threshold = CONSENSUS_THRESHOLDS[panel];

    if (panel === 'E') {
        // Для E: проверка разброса
        const min = Math.min(...scores);
        const max = Math.max(...scores);
        const range = max - min;

        if (range > threshold) {
            return {
                required: false,
                recommended: true,
                range: range,
                message: `Большой разброс E-судей: ${range}`
            };
        }
    } else {
        // Для D и A: проверка разницы между двумя судьями
        const [s1, s2] = scores;
        const diff = Math.abs(s1 - s2);

        if (diff > threshold) {
            return {
                required: (panel === 'D'),
                recommended: (panel === 'A'),
                difference: diff,
                message: `Разница ${panel}: ${diff}`
            };
        }
    }

    return { required: false, recommended: false };
}
```

### 11.3. Проверка временных рамок

```javascript
const DURATION_LIMITS = {
    individual: { min: 75, max: 90 },    // 1'15" - 1'30"
    group: { min: 135, max: 150 }        // 2'15" - 2'30"
};

function validateDuration(type, seconds) {
    const limits = DURATION_LIMITS[type];

    if (!limits) {
        return { valid: false, error: 'Неизвестный тип упражнения' };
    }

    if (seconds < limits.min) {
        const shortage = limits.min - seconds;
        const penalty = shortage * 0.05;

        return {
            valid: true,
            warning: true,
            message: `Упражнение короче на ${shortage} сек`,
            penalty: penalty
        };
    }

    if (seconds > limits.max) {
        const excess = seconds - limits.max;
        const penalty = excess * 0.05;

        return {
            valid: true,
            warning: true,
            message: `Упражнение длиннее на ${excess} сек`,
            penalty: penalty
        };
    }

    return { valid: true, warning: false };
}
```

## Заключение

Данный документ предоставляет полную техническую спецификацию правил FIG 2025-2028 для разработки программного обеспечения по художественной гимнастике.

**Ключевые моменты для разработчиков:**

✅ **Оценка D:** Среднее двух судей, консенсус при разнице > 0.5
✅ **Оценка E:** Среднее без макс/мин из 4-6 судей
✅ **Оценка A:** Среднее двух судей
✅ **Total:** D + E + A (с учётом нейтральных сбавок)
✅ **Тай-брейк:** E → D → A → равные места
✅ **Валидация:** Диапазоны, консенсус, длительность

**Рекомендации:**
- Использовать WebSocket для синхронизации оценок в реальном времени
- Реализовать автоматическую проверку консенсуса
- Предоставить судьям визуальные подсказки при ошибках
- Логировать все изменения оценок (audit trail)
- Поддерживать офлайн-режим с последующей синхронизацией
