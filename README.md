## 🎯 О проекте

### Цель

Создание универсальной web-системы для организации и проведения соревнований по художественной гимнастике с полной поддержкой правил FIG 2025-2028.

### Ключевые возможности

- ✅ **Управление соревнованиями** — создание, редактирование, настройка программы
- ✅ **Регистрация участников** — импорт, жеребьёвка, стартовые протоколы
- ✅ **Судейская система** — бригады D, E, A по правилам FIG
- ✅ **Секретариат** — приём оценок, формирование протоколов
- ✅ **Real-time** — WebSocket синхронизация, табло, мобильное приложение
- ✅ **Гибридный режим** — локальная сеть + облачная синхронизация

### 3. Правила FIG 2025-2028 для ПО

**Файл:** [ПРАВИЛА_FIG_2025-2028_ДЛЯ_ПО.md](./ПРАВИЛА_FIG_2025-2028_ДЛЯ_ПО.md)

**Содержание:**

#### Раздел 1-2: Введение и структура судейства
- Типы соревнований и возрастные категории
- Состав судейских бригад (D, E, A)
- Временные рамки и требования

#### Раздел 3: Оценка D (Difficulty — Сложность)
- Компоненты: D_body, D_apparatus, D_dance
- Уровни сложности элементов (A-I, 0.10-0.80+)
- Формулы расчёта
- Правила консенсуса

**Пример кода:**
```javascript
function calculateD(D1, D2) {
    const difference = Math.abs(D1 - D2);
    if (difference > 0.5) {
        return { status: "CONSENSUS_REQUIRED", ... };
    }
    return { status: "OK", D: (D1 + D2) / 2 };
}
```

#### Раздел 4: Оценка E (Execution — Исполнение)
- Система сбавок от 10.0
- Категории ошибок (мелкие -0.10, критические -1.50+)
- Расчёт консенсуса (убрать max/min, среднее из средних)
- Детальные таблицы сбавок

**Пример:**
```
E-судьи: [9.00, 8.60, 8.85, 8.70]
Убираем: max=9.00, min=8.60
E = (8.85 + 8.70) / 2 = 8.775
```

#### Раздел 5: Оценка A (Artistic — Артистизм)
- Критерии: музыкальность, хореография, единство, оригинальность
- Диапазон: 0.0 - 10.0
- Расчёт: среднее арифметическое судей

#### Раздел 6: Итоговая оценка
**Формула:**
```
TOTAL = D + E + A
```

**Полный пример:**
```
D = 5.15  (среднее 5.20 и 5.10)
E = 8.775 (среднее без max/min)
A = 9.15  (среднее 9.10 и 9.20)
→ TOTAL = 23.075
```

#### Раздел 7: Правила ранжирования
**Тай-брейк при равенстве Total:**
1. Выше E (исполнение)
2. Выше D (сложность)
3. Выше A (артистизм)
4. Равные места

```javascript
function compareAthletes(a, b) {
    if (a.Total !== b.Total) return b.Total - a.Total;
    if (a.E !== b.E) return b.E - a.E;
    if (a.D !== b.D) return b.D - a.D;
    if (a.A !== b.A) return b.A - a.A;
    return 0; // Равные
}
```

#### Раздел 8: Технические требования
- Длительность упражнений (индивид. 75-90 сек, группа 135-150 сек)
- Размер площадки (13×13 м)
- Обязательные элементы

#### Раздел 9: Сбавки и штрафы

- Дисквалификация
