## 2. Назначение и цели создания системы

### 2.1. Назначение системы

Система предназначена для **комплексной автоматизации** процессов организации и проведения соревнований по художественной гимнастике на всех уровнях: от местных турниров до национальных первенств.

### 2.2. Цели создания

#### 2.2.1. Основные цели

1. **Автоматизация судейства** по правилам FIG 2025-2028
   - Цифровое выставление оценок D, E, A
   - Автоматический расчёт итоговой оценки
   - Контроль консенсуса судей

2. **Организация соревнований**
   - Создание и управление турнирами
   - Регистрация участников
   - Формирование расписания

3. **Минимизация ошибок**
   - Валидация оценок в реальном времени
   - Автоматические проверки правил
   - Исключение ручного подсчёта

4. **Прозрачность результатов**
   - Публикация результатов в реальном времени
   - Доступ для зрителей и тренеров
   - Формирование протоколов

#### 2.2.2. Целевая аудитория

| Роль | Количество (на 1 соревнование) | Функции в системе |
|------|--------------------------------|-------------------|
| **Организатор** | 1-2 | Создание соревнований, управление |
| **Главный судья** | 1 | Формирование бригад, контроль |
| **Судьи** | 12-36 | Выставление оценок D, E, A |
| **Секретарь** | 2-4 | Приём оценок, протоколы |
| **Тренеры/Участники** | 50-200 | Просмотр расписания и результатов |
| **Зрители** | Неограниченно | Просмотр результатов онлайн |

### 2.3. Ожидаемые результаты

**Количественные показатели:**
- Сокращение времени на обработку результатов: **в 10 раз** (с 30 мин → 3 мин)
- Снижение ошибок при подсчёте: **до 0%** (исключение ручного счёта)
- Ускорение выставления оценок судьями: **на 30%** (цифровой интерфейс)
- Доступность результатов: **в режиме реального времени** (< 5 сек задержка)

**Качественные показатели:**
- Соответствие международным правилам FIG 2025-2028
- Удобство интерфейса для всех ролей
- Надёжность работы в локальной сети
- Масштабируемость (от 10 до 500 участников)

## 3. Характеристика объекта автоматизации

### 3.1. Описание процесса проведения соревнований

#### 3.1.1. Этапы соревнования

```
ПОДГОТОВКА (за 1-4 недели)
├─ Создание соревнования
├─ Регистрация участников
├─ Формирование судейских бригад
└─ Жеребьёвка и стартовые протоколы

ПРОВЕДЕНИЕ (1-4 дня)
├─ День 1: Открытие, квалификация
├─ День 2-3: Многоборье
├─ День 4: Финалы, награждение
│
└─ Процесс каждого выступления:
    ├─ Вызов участника
    ├─ Разминка на ковре (30 сек)
    ├─ Выступление (75-90 сек)
    ├─ Судьи выставляют оценки (2 мин)
    ├─ Секретарь принимает оценки
    ├─ Расчёт итоговой оценки
    └─ Публикация результата

ЗАВЕРШЕНИЕ
├─ Формирование итоговых протоколов
├─ Награждение победителей
└─ Архивация данных
```

#### 3.1.2. Судейский процесс (по FIG 2025-2028)

**D-бригада (2 судьи):**
```
D1 оценивает сложность → D1 = 5.20
D2 оценивает сложность → D2 = 5.10

Если |D1 - D2| > 0.5:
    → Консенсус (обсуждение и корректировка)
Иначе:
    → D = (D1 + D2) / 2 = 5.15
```

**E-бригада (4 судьи):**
```
E1 → 9.00
E2 → 8.60
E3 → 8.85
E4 → 8.70

Убрать max (9.00) и min (8.60)
E = (8.85 + 8.70) / 2 = 8.775
```

**A-бригада (2 судьи):**
```
A1 → 9.10
A2 → 9.20

A = (A1 + A2) / 2 = 9.15
```

**Итого:**
```
TOTAL = D + E + A = 5.15 + 8.775 + 9.15 = 23.075
```

### 3.2. Существующие проблемы

| Проблема | Описание | Последствия |
|----------|----------|-------------|
| **Ручной подсчёт** | Секретарь считает на калькуляторе | Ошибки, задержки 15-30 мин |
| **Бумажные протоколы** | Судьи пишут на бумаге | Нечитаемый почерк, потеря данных |
| **Нет валидации** | Оценки не проверяются автоматически | Ошибки вне диапазона |
| **Задержка результатов** | Зрители ждут окончания всего потока | Низкая вовлечённость |
| **Сложный консенсус** | Судьям трудно обсуждать расхождения | Субъективные решения |

### 3.3. Требуемые улучшения

✅ **Автоматизация** → Цифровые оценки, автоматический расчёт
✅ **Валидация** → Проверка диапазонов, выявление расхождений
✅ **Real-time** → Результаты через 5 секунд после выступления
✅ **Прозрачность** → Все данные доступны участникам
✅ **Надёжность** → Работа в локальной сети без интернета
